# Bitácora de uso de IA

Se utilizó IA como apoyo para revisar y desarrollar partes del proyecto Django.

## RF-01

Se solicitó ayuda para crear los modelos del diagrama, sus relaciones,
restricciones, configuración del Django Admin y datos de prueba.

## RF-02

Se solicitó ayuda para configurar el inicio y cierre de sesión, los roles de
cliente y encargado, la protección de vistas y la duración de la sesión.

## RF-03

Se solicitó ayuda para crear el catálogo del cliente, la búsqueda por nombre,
el filtro por categoría, el formato de precios y la marca de productos
agotados.

## RF-06

Se solicitó ayuda para crear el historial de pedidos del cliente, el detalle,
la cancelación de pedidos pendientes y el avance de estados por parte del
encargado.

## Revisión

Se revisaron las propuestas, se adaptó el código al proyecto y se ejecutaron
las pruebas para corregir errores.
